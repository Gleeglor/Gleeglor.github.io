Protocol Kardashev

2024–2026 Processing / Java Active

A diggable colony sandbox about resource loops, crashed landers, and climbing the Kardashev scale — scrape for scraps, then lean into systems that snowball if you push them.

Where it is now

The live game is a 2D Processing sidescroller: diggable crust, soft fog vision, colony HUD, research, and a ship Construction editor. An earlier C / Flecs / Box2D prototype taught me what not to carry forward; this sketchbook build is the one I'm iterating on.

Dev notes and playtest write-ups live in the space repo (VitePress updates under docs-site/updates/).

Recent progress

Pulled from the space changelog and playtest posts (not a wishlist):

  • Construction editor — craft-block grid (W×H tiles, 90° rotate, orthogonal connect); multi-select, drag-move, copy/paste; kit palette with cost chips; Reassembly-style attach tint plus mass / HP / thrust / energy stats
  • Designs vs blueprints — hull Save/Load for vessel and Colony lander designs; separate stamp Blueprints library; trash delete on file-backed rows
  • New colony lander picker — built-in Colony lander first, then custom saved landers
  • Research / mycelium gate — Theoretical research tree; Mycelium understanding unlocks Claim land and map expand; early build catalog gated until then
  • Theoretical physics (ore) — cataloged route for mining / smelting / fabrication (spec-first; live unlock graph still next)
  • Megastructure ladder — ring slice → orbital ring → interplanetary station → star ring at ×100 scale steps; Construction ring mode stays a schematic mini-grid
  • Colony loop chrome — crash Initiate boot, circular fog vision, Tile probe, Processes pipelines, Base / Research hologram panels
